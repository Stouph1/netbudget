# Annonce NETbudget 2.0 · vidéo de lancement

Deux rendus de 60 s : `annonce-2.0-16x9.mp4` (site, YouTube, LinkedIn, Google Ads) et `annonce-2.0-9x16.mp4` (Reels Instagram, TikTok, Shorts).
Compositions HyperFrames dans `video/` et `video-reels/` ; rendu : `npx hyperframes@0.8.157 render --workers 1` dans chaque dossier.

Structure, calée sur les mesures de Launch Scene (242 vidéos de lancement, 19 fintech) : hook 0–2,5 s, produit nommé sur le drop à 2,5 s, six écrans réels 7,5–35 s, trois affirmations 35–42,5 s, globe « 59 pays » 42,5–47,5 s, formules 47,5–52,5 s, appel à l'action 52,5–57,5 s (87 % de la durée), sortie. Musique « The Mountain » (95,7 BPM), coupes sur les temps.
Faits utilisés, tous vérifiés dans l'app : 282 conseils, 59 pays, Eurostat / BLS / ONS, trois formules. Aucun prix, aucun emoji, aucun concurrent.
