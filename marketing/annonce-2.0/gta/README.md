# Annonce 2.0, version Vice (hommage)

Ambiance coucher de soleil néon, soleil strié, palmiers, grille, lignes de balayage.
Aucun élément de Rockstar : ni logo, ni police, ni musique, ni nom du jeu à l'écran.
Le lien se fait par la date : le jeu sort le 19 novembre 2026, NETbudget 2.0 le 15, quatre jours avant.

- `video/index.html` : composition 16:9 (32 s), plans réels enregistrés sur simulateur.
- `build.py` : dérive le format Reels 9:16 et rend les deux (`python3 build.py render`).
- Musique : « Sun in Your Eyes », Mixkit, licence commerciale sans attribution. Le temps fort à 28,24 s tombe sur l'apparition du logo (9,6 s).
